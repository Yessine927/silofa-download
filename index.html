Version 1.0.0

Vos factures électroniques TEIF, installées en un clic

SILOFA crée vos factures au format TEIF, les signe avec vos certificats et les envoie à TTN. Téléchargez l’installateur, double-cliquez, c’est prêt.

SILOFA pour Windows

silofa-1.0.0-setup.exe Télécharger l’installateur

Windows 10 ou 11, 64 bits · environ 117 Mo

Installation impossible sur ce PC ? La version portable se lance sans rien installer.

Trois étapes

  1. Téléchargez

    Le bouton ouvre Google Drive : cliquez sur Télécharger. Pour un fichier de cette taille, Drive précise qu’il ne peut pas l’analyser ; cliquez sur Télécharger quand même pour enregistrer silofa-1.0.0-setup.exe.

  2. Double-cliquez

    L’installation se fait seule, sans question ni droits administrateur. L’icône SILOFA apparaît sur le bureau et dans le menu Démarrer, puis l’application s’ouvre.

  3. Commencez

    Créez votre compte, puis ajoutez vos certificats de signature et de cachet dans Paramètres.

Configuration requise

  • Windows 10 ou Windows 11, 64 bits
  • 8 Go de mémoire conseillés (4 Go suffisent)
  • 6 Go d’espace libre pour l’import intelligent des PDF
  • Une connexion Internet au premier lancement

Premier téléchargement et lancement

SILOFA prépare en arrière-plan l’IA qui lit vos factures PDF, directement sur votre PC : environ 3,5 Go, téléchargés une seule fois. Vous pouvez utiliser l’application pendant ce temps.

SILOFA est nouveau, donc Windows ne le connaît pas encore et affiche des avertissements. Le fichier est sûr ; voici comment les passer :

  • Microsoft Edge indique que le fichier « n’est pas fréquemment téléchargé » : cliquez sur … puis Conserver, puis Afficher plus et Conserver quand même.
  • Windows affiche « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis sur Exécuter quand même.
Vos factures, vos certificats et vos réglages restent sur votre PC.
